Publishing workflow

Homepage: export homepage-data.json

Products: export products-data.json

Projects: export projects-data.json

Certificates: export certificates-data.json

Blog: export blog-data.json

Settings: export site-config.json

After replacing exported files, run python build-site.py from the website folder. It rebuilds all public Thai and English pages from the editor data.
