Green Running Tracks โดย HKS Surfaces

HKS Surfaces ให้บริการพื้นสนามกรีฑาประสิทธิภาพสูง แข็งแรงทนทาน สำหรับโรงเรียน สนามกีฬา และศูนย์กีฬา โดยสามารถปรับระบบให้เหมาะกับความต้องการด้านสมรรถนะ งบประมาณ ระดับการใช้งาน และสภาพพื้นที่ของแต่ละโครงการ

ระบบพื้นลู่วิ่ง

ระบบสเปรย์โค้ต (Spray-Coat Track System)

ระบบพื้นแบบซึมน้ำได้ในราคาคุ้มค่า เหมาะสำหรับสนามฝึกซ้อมและพื้นที่อเนกประสงค์ โครงสร้างประกอบด้วยชั้นยาง SBR ที่มีความยืดหยุ่น และผิวสเปรย์ EPDM ซึ่งให้การยึดเกาะ ความสบาย และสมรรถนะที่เชื่อถือได้สำหรับการใช้งานทั่วไป โครงสร้างโดยทั่วไป: เส้นสนาม ผิวสเปรย์ EPDM ชั้นยาง SBR ไพรเมอร์ และฐานแอสฟัลต์หรือคอนกรีต

ระบบแซนด์วิช (Sandwich Track System)

ระบบปิดผิวที่ทนน้ำ ออกแบบมาสำหรับการใช้งานหนัก ชั้นยาง SBR ช่วยรองรับแรงกระแทก ปกป้องด้วยชั้นซีลโพลียูรีเทน และปิดผิวด้วย EPDM ที่ทนทาน ให้ความสมดุลระหว่างความสบาย ความยืดหยุ่น และอายุการใช้งาน โครงสร้างโดยทั่วไป: เส้นสนาม ผิวหน้า EPDM ชั้นซีลโพลียูรีเทน ชั้นยาง SBR ไพรเมอร์ และฐานแอสฟัลต์หรือคอนกรีต

ระบบฟูลพัวร์ (Full-Pour Track System)

ระบบโพลียูรีเทนไร้รอยต่อระดับพรีเมียม เหมาะสำหรับสนามแข่งขันและสนามกรีฑามืออาชีพ โครงสร้างยืดหยุ่นหลายชั้นให้แรงส่งกลับ การยึดเกาะ และสมรรถนะที่สม่ำเสมอสำหรับการใช้งานหนักในระยะยาว ระบบฟูลพัวร์นี้ผ่านการรับรองมาตรฐาน IAAF โดยการรับรองครอบคลุมผลิตภัณฑ์ ระบบ และข้อกำหนดการติดตั้งตามที่ระบุในใบรับรอง โครงสร้างโดยทั่วไป: เส้นสนาม ผิวหน้า EPDM ชั้นโพลียูรีเทนยืดหยุ่น ไพรเมอร์ และฐานแอสฟัลต์หรือคอนกรีต

ระบบพื้นสำเร็จรูป (Prefabricated Track System)

พื้นยางแบบม้วนที่ผลิตและควบคุมคุณภาพจากโรงงาน ให้ความหนาสม่ำเสมอ ติดตั้งรวดเร็ว และมีสมรรถนะที่เชื่อถือได้ เหมาะสำหรับโครงการที่ให้ความสำคัญกับคุณภาพที่แน่นอนและการส่งมอบอย่างมีประสิทธิภาพ ระบบพื้นสำเร็จรูปนี้ผ่านการรับรองมาตรฐาน IAAF โดยการรับรองครอบคลุมผลิตภัณฑ์ ระบบ และข้อกำหนดการติดตั้งตามที่ระบุในใบรับรอง โครงสร้างโดยทั่วไป: เส้นสนาม ชั้นพื้นลู่สำเร็จรูป กาวประสาน และฐานแอสฟัลต์หรือคอนกรีต

การเลือกระบบพื้นลู่วิ่งที่เหมาะสม
